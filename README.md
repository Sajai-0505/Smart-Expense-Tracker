# Smart Expense Tracker

## Project Overview

Smart Expense Tracker is a Python-based console application designed to manage daily expenses and analyse spending patterns. It helps users maintain expense records and understand their monthly spending.

## Features

* Add new expenses with date, category and description.
* View complete expense history.
* Calculate monthly expenditure.
* Generate category-wise spending summaries.
* Calculate spending percentages.
* Delete unwanted expense records.
* Store expense details using CSV file handling.

## Technologies Used

* Python 3
* CSV File Handling
* Date and Time Module
* Collections Module

## How to Run

1. Install Python 3.
2. Download or clone this repository.
3. Open the project folder in a terminal.
4. Execute the following command:

```bash
python main.py
```

5. Select an option from the displayed menu.
